Clinic Voice Agent

An assistant that books, reschedules and cancels clinic appointments by voice or by text chat. The caller picks Talk or Type and a language on a web page.

  • Python
  • LiveKit Agents
  • SQLite
  • pytest
Voice calls working in English and Arabic
View code →

agentHi! I can book, reschedule or cancel your appointment.

  1. Talk mode: speech-to-text, then an LLM, then text-to-speech, with a live transcript. The caller can type at any time, which helps with names and phone numbers.
  2. Type mode: the LLM only, so replies are faster and cheaper. Both modes share the same tools, rules and calendar.
  3. Booking core: a SQLite calendar with one booking per slot and idempotent booking, plus phone checks and an audit log.
  4. Speech: dates, times and digits turned into natural spoken phrases in all five languages.

Next up: speed tuning for voice, scripted test conversations, and SMS or WhatsApp confirmations. Demo doctors and clinic details are fictional.

03 / 04

Air-Writing

Paint and write text in the air with your index finger, using only a webcam. A small neural network reads the capital letters you write and learns your handwriting from your corrections.

  • Python
  • OpenCV
  • MediaPipe
  • NumPy
Working app
View code →
Try it: write a letter here with your mouse or finger
  1. Hand tracking: MediaPipe finds 21 landmarks per frame. Gestures switch between drawing, a pointer for the toolbar, and a fist to clear.
  2. Smooth strokes: a One Euro filter removes jitter at slow speeds without adding lag at fast ones, and gestures must hold for 3 frames.
  3. Letter recognition: strokes are rendered to 28×28 and classified by an MLP (784 → 256 → 128 → 26) written in NumPy, scoring 99.8% on unseen synthetic letters.

The pad above runs in your browser with the mouse. The real app does the same with your fingertip and a webcam.
